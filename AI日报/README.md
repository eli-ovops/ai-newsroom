# AI 日报固定制作流程

版本：`AI-DAILY-20261025-v4`。用户2026-10-25指定；所有日报在本Codex项目制作。每次开工先读本流程与[编辑与视觉规范](编辑与视觉规范.md)，后者维护内容判断、三种任务模式及详情页的自主版式边界。发布准备另沿[图文正文与BGM要求](../内容生产流程.md#发布包bgm与图文正文2026-10-25)。

## 内容定位

新闻播报型图文：今天AI圈发生了什么。题材开放，不固定四类栏目。模型与跑分、GitHub开源、创作工具、大厂动态仅为例子；也可补充AI硬件与机器人、产品功能、价格与开放范围、研究突破、行业应用及其他值得关注的消息。按当天新闻价值选题，不为了填栏目凑消息，不强制改成老板教程、个人项目复盘或长篇观点。可用一句话解释用途，少堆术语。Codex自行补充的新闻先作为候选给用户确认，确认后纳入本期；用户已提供并指定采用的新闻不重复索取选题批准。

用户提供的新闻、数字、链接及“已核实”描述均为候选输入，不能自动等于本项目核实。去重后查原公告、仓库、论文：核事件日期、型号、数字和条件。跑分分清基准版本与测试来源；API价分清输入/输出/缓存和单位；Stars注明查询时点，老仓库高Star不等于今天新开源；速度保留硬件、分辨率、时长、采样条件。“Grok内置Opus”等说法要分清Grok模型、Grok Bot应用和第三方入口，证据不足不作确定新闻。外部`/workspace/`素材路径不代表本机已收到素材。

用户日期优先；“今天”按Asia/Shanghai。信息来源必须在本期执行时实时查询，不能沿用旧聊天、旧摘要或模型记忆作为最新消息。优先当日/近24小时的原始公告和新事件；逐条记录原始发布时间、事件日期、一手链接与本期查询时间，并核最新进展、修订或撤回。资料新发布不等于事件新发生，今日转发不等于今日新闻。发布计划写清未来日期，宣布/灰度/正式上线/开源权重分清。没有足够新消息就少选或报告，不静默扩展日期凑数；较旧但有价值的背景消息单列候选并明示日期，用户确认后再纳入。导出前只对已选消息做必要的最新状态复核，不重复广泛搜索。无法访问原文或核实最新状态的标为待核，不包装成已核实新闻。缺少新闻输入时只检索本期必要的一手消息，不做广泛对标研究。

## 固定母版与交付

母版：`/Volumes/EXTERNAL/自媒体/ai_daily_editorial_replica_20261025_144029`。复用现有字体、素材、报头、排版和导出脚本，默认reference主题，保持已确定风格。局部构图、断行、图文比例等由Codex按内容自主决定，不逐项询问；品牌或重要整体结构变化先说明必要性。日常不重跑字体筛选、素材提取或模板搭建；只有发现母版具体问题时局部修复。素材按新闻相关性选用，不为统一固定出现无关科技插图。

当前仅做1086×1448总结封面，详情图等用户明确要求。当前母版容量为四条，条目数是版式容量，不代表固定四类栏目；可同类多条，也可四条来自不同题材。分类标签按实际新闻修改，不固定为模型/开源/工具/行业。候选较多时筛选四个重点，不把长文硬塞封面。新闻不足如实说明，不编造凑数；需要调整条数或布局时先说明原因。

每期保存于`AI日报/期刊/YYYY-MM-DD/v01/`；同日返修用v02等新目录，不覆盖历史成图。源码、字体、素材、配置、脚本保留项目内部；默认直接展示PNG成图并给图片绝对路径。只有用户明确要求备份或完整工程才打ZIP。

## 每期执行

1. 接收日期和新闻，去重并核本期原始来源；保存本期来源与必要截图。
2. 将母版`config/baseline.json`复制为本期`content.json`；修改日期、新闻、分类等字段。第一条用两行`headlineLines`，其余用`headline`。真实新闻核实后才移除示例提示，阅读分钟数为明确配置，不假称自动统计。
3. 使用现有脚本导出到本期目录：

```bash
python3 /Volumes/EXTERNAL/自媒体/ai_daily_editorial_replica_20261025_144029/build.py --config /Volumes/EXTERNAL/自媒体/AI日报/期刊/YYYY-MM-DD/v01/content.json --output-dir /Volumes/EXTERNAL/自媒体/AI日报/期刊/YYYY-MM-DD/v01/output
```

默认直接使用已有字体与素材，不调用提取步骤。`--rebuild-assets`只用于明确的母版问题修复。

4. 只核本期变化：日期/星期、文字与分类、旧字残留、来源、页码、溢出、遮挡及实际PNG约390px宽手机阅读。标题长先编辑断行，正文多先去重复次要信息；保留事实及必要限制，不无限缩字、不静默删内容。不重复完整母版比对流程，不为普通排版另建测试工程或长报告。
5. 默认以绝对路径Markdown图片展示`output/custom.png`并给PNG路径；2倍版内部保留，按需提供。日常不附源码包或ZIP。

用户说“做今天的日报”即执行本流程，不另问是否开始。此约定不创建定时任务、不授权自动发布、不恢复暂停Bot。平台发布按本条另行授权。

用户要求准备发布时，按完整图文帖整理详细正文、图片顺序、标题、话题、来源和BGM状态。正文补图片信息，不仅复述标题。以后所有内容默认检查BGM；图文在支持的平台原生添加音乐，PNG不含音频。本期音乐待用户挑选，准备不等于发布。音乐规则唯一维护在上述发布包要求，不另建重复音乐台账。
